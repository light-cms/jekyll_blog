date: '2026-10-16T18:24:00Z'
---

To add a post, create a Markdown file in `_posts/` named `YYYY-MM-DD-title.md` with this front matter:

```md
---
layout: post
title: My Post
---
```

It will automatically appear on the home page and in the feed.
