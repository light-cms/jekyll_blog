## About

This is a basic displayable Jekyll starter. It includes:

- Home page (`index.md`) listing `site.posts`
- About page (`about.md`)
- Post layout (`_layouts/post.html`)
- Two sample posts in `_posts/`
- Plain CSS in `assets/css/style.css`
- RSS feed via `jekyll-feed`

Run `bundle exec jekyll serve` to preview, `bundle exec jekyll build` to build to `_site/`.
